# Rahmah Abdulkarim — Portfolio

A responsive, dependency-free portfolio designed for GitHub Pages.

## Preview locally

Open `index.html` directly, or serve this directory with any static web server.

## Publish at an independent GitHub Pages URL

Create a public repository named `rahmahh53.github.io`, add these files at the repository root, and push to the `main` branch. In the repository settings, choose **Pages → Deploy from a branch → main / root**. The site will be available at:

`https://rahmahh53.github.io`

A purchased custom domain can also point to the same Pages site later.
